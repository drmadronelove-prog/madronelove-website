# Reimbursement service logos

The Fees page looks for a logo here for each service and falls back to the
plain wordmark when the file is missing. Add files named after the slug in
`app/fees/page.tsx`:

- `reimbursify.svg`
- `mentaya.svg`

`.svg` is preferred; `.png` and `.webp` also work. Logos render at 28px tall,
so use artwork with transparent padding trimmed off.

Download each from the company's own press or brand page so the mark is the
official current one, and check their brand guidelines — these are third-party
trademarks, usable to identify and link to the service but not in any way that
implies endorsement.
